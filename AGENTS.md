# Language conventions

Everything developer-facing is in English: identifiers, file names, comments, tests, logs,
commit messages and documentation. Text the end user sees stays in Spanish: UI copy, the
error messages the API returns for display, Spanish SRD content and the URL paths (`/personajes`, ...).
